# ふせじ文庫

小説の一部が伏字になっていて、前後の流れを読んで入る言葉を当てるゲーム。
ページが進むほど難しくなる（選ぶ → 書く → 文をまるごと書く）。

## 遊び方

`index.html` をダブルクリックしてブラウザで開くだけ。インターネットもサーバも要らない。
記録（どこまで進んだか・各ページの最高点）はそのブラウザの中だけに残る。

### ひとページ百話

目次のいちばん上にある、1ページで終わる短い話100本（Lv.1〜4 が17本ずつ、Lv.5〜6 が16本ずつ）。
やさしい話から順に並んでいて、**同じ難易度を3話こなすと次の難易度が開く**。開いた難易度の中では、どの話から読んでもよい。
「つづきから」はまだ読んでいない一番前の話、「おまかせで1話」は開いている話（まだ読んでいないものを優先）からランダムに選ぶ。
1話ごとに完結するので「前のページを読み返す」は出ない。

### 縦書き／横書き

画面の右上の「縦書き｜横書き」で切り替えられる（はじめは縦書き。選んだ向きは覚えておく）。
縦書きでは本文が右から左へ進み、入りきらない分は本文の枠の中で左右にスクロールする。
続きがあるあいだは、枠の下に「◀ 左へスクロールすると続きがあります」と出る。
伏字の欄（選ぶ・書く・文を書く）も縦向きになる。ヒントや点数の表示は横書きのまま。

### 前のページを読み返す

2ページ目からは「前のページを読み返す」ボタンが出る。解いているページより前のページだけを、伏字に正解を入れた形で重ねて表示する（先のページは見られない）。
「◯ページ目に戻る」か Esc で閉じると、書きかけの答えはそのまま残っている。

## 難易度

| Lv | 名前 | 遊び方 |
|---|---|---|
| 1 | やさしい | 3つの選択肢から選ぶ |
| 2 | ふつう | 4つから選ぶ。まぎらわしい答えも混ぜる |
| 3 | ややむずかしい | 自分で書く。□の数で文字数がわかる |
| 4 | むずかしい | 自分で書く。文字数ヒントなし、伏字が増える |
| 5 | とてもむずかしい | 言葉のかたまり（句）を書く |
| 6 | 達人 | 文をまるごと書く |

- Lv.3 から「ヒント」（最初の文字）が使える。使った伏字は半分の点。
- 句・文の伏字は「大事な言葉が入っているか」で ○ / △ / × を付ける。
  判定しきれないことがあるので、「この答えでも合っている」で自分で○にできる。
- 判定では、ひらがな/カタカナ、全角/半角、句読点や空白の違いは気にしない。
- **読みが同じなら表記は問わない**。漢字の読み辞書で入力を読みに直し、正解の読み（ひらがなの別解）と同じに読めれば○。
  例：正解「ひっこし」に対して 引っ越し・引越し・引越・引っこし・ひっこし はすべて○。
  そのときは答えの横に「（読みが同じ：ひっこし）」と出る。
  同じ読みの別の言葉（傘と笠など）も○になる。
- 句・文の伏字では、ひらがな3文字以上の鍵語について「読みが同じ部分があるか」も見る。

## 漢字の読み辞書

- `kanji.js` … 漢字ごとの音読み・訓読み（約6,500字、JIS第1・第2水準）。
  元データは [KANJIDIC2](https://www.edrdg.org/wiki/index.php/KANJIDIC_Project)（Electronic Dictionary Research and Development Group、CC BY-SA 4.0）。
  `node tools/build-kanji.js <kanjidic2.xml.gz>` で作り直せる（手で直さない）。
- `yomi.js` … 読みで比べるしくみ。送りがなの省略（引越）、促音（ひき→ひっ）、連濁（かさ→がさ）も読めるようにしている。
  1字ずつでは読めない語（今日・大人・文字・母さん など）は、`yomi.js` の `WORDS` に足す。

## 物語の足し方（stories.js）

`window.STORIES` に物語を足す。1ページ＝1つの `{ level, title, text }`。
1ページで終わる短い話は `shorts/lv1.js`〜`lv6.js` の `window.SHORTS` に足す（難易度ごとのファイル。並び順は自動で難易度順になる）。
短い話は、手がかりをそのページの中だけに置く。Lv.1〜4 は言葉の伏字、Lv.5〜6 は句・文の伏字だけを使う。

```
[正解/別解/別解|ダミー/ダミー]
```
言葉の伏字。`/` で別解を並べる（漢字・ひらがな両方を書いておくと親切）。
`|` の後ろはダミーの選択肢で、Lv.1〜2 のときだけ使う（Lv.1 は2つ、Lv.2 は3つが目安）。
**別解には必ずひらがなの読みを1つ入れる**（例：`[引っ越し/ひっこし]`）。読みで比べるときはこれを正解の読みとして使う。
同じ意味の別の言葉を別解にするときは、その言葉の読みも入れる（例：`[文字/もじ/筆跡/ひっせき]`）。

物語を書き足したら `node tools/check-stories.js` で点検する（読みの入れ忘れ、ダミーの数、鍵語の組などを調べる）。

```
[[見本の文|鍵語,鍵語;鍵語,鍵語]]
```
句・文の伏字。`;` で区切った「組」ごとに、`,` で並べた言葉のどれか1つが入っていれば合格。
すべての組が合格なら○、一部なら△。見本の文と同じなら無条件で○。
見本が12文字以下なら文中に小さな欄、それより長ければ段落の書き込み欄になる。

- 行頭に `>` を付けると、手紙などの引用として字下げして表示する。
- 鍵語は短すぎると何にでも当たってしまう（「は」「あ」など1文字のかなは避ける）。

## ファイル

- `index.html` … 入口
- `game.js` … 画面・判定・記録
- `kanji.js` / `yomi.js` … 漢字の読み辞書と、読みで比べるしくみ
- `tools/` … 辞書の作り直し（build-kanji.js）と物語の点検（check-stories.js）
- `shorts/lv1.js`〜`lv6.js` … ひとページ百話（難易度ごとに1ファイル）
- `stories.js` … 物語データ（「雨やどりの詩集」「夜の音楽室」「月面のパン屋」各8ページ。どれも Lv.1,1,2,2,3,4,5,6 の順）
- `style.css` … 見た目（暗い画面設定にも対応）
